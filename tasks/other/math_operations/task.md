# Math Operations: Calculator via Lambda

## Описание

Калькулятор для двух чисел через функциональный интерфейс.
Задача — создать `MathOperation` с методом `double calculate(double a, double b)`,
написать метод `executeMath(double a, double b, MathOperation op)`.

В `Main` через lambda выполнить три операции:

1. Сложение
2. Умножение
3. Процент второго числа от первого `(b / a) * 100`

## Запуск

```java
Main.main(args)
// Вывод:
// 150.0
// 5000.0
// 50.0
```
