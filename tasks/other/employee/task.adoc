# Employee: Lambda — сортировка по зарплате

## Описание

Класс `Employee` (поля: `String name`, `double salary`).
Задача — отсортировать сотрудников **по зарплате по убыванию**.
При одинаковой зарплате — **по имени в алфавитном порядке**.
Использовать lambda-выражение (без отдельного класса-компаратора).

## Запуск

```java
Main.main(args)
// Вывод: список сотрудников, отсортированный по убыванию зарплаты
```
