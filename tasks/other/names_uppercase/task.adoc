# Names Uppercase: Stream API

## Описание

У вас есть список имен, написанных строчными (маленькими) буквами (например:
"Sada", "Şəhanə", "Ayşən","Aysel").
Вы должны перевести все имена в этом списке в верхний регистр (ALL CAPS /
UpperCase).
Использовать классический цикл for ЗАПРЕЩЕНО.

## Запуск

```java
Main.main(args)
// Вывод: [SADA, SEHANE, AYSEN, AYSEL]
```
