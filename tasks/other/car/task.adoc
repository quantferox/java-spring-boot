# Car: Comparator — сортировка по цене

## Описание

Класс `Car` (поля: `String model`, `double price`).
**Запрещено** добавлять `implements Comparable` внутрь класса `Car`.
Задача — создать отдельный класс `CarPriceComparator` (`Comparator<Car>`)
и отсортировать автомобили **от дешёвых к дорогим**.

## Запуск

```java
Main.main(args)
// Вывод: автомобили отсортированы по цене по возрастанию
```
