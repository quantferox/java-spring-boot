# Product: Lambda — сортировка по названию

## Описание

Класс `Product` (поля: `String name`, `double price`).
Задача — отсортировать продукты **по названию в алфавитном порядке**.
Вместо отдельного класса передать в `sort()` lambda-выражение напрямую.

## Запуск

```java
Main.main(args)
// Вывод: продукты в алфавитном порядке по name
```
