# Even Filter: Stream API

## Описание

Вам дан список (List), состоящий из произвольных чисел от 1 до 20. Ваша
задача — с помощью Stream API найти из этого
списка только четные числа, собрать их в новый список (List) и вывести на
экран.

`List<Integer> numbers = Arrays.asList(5, 12, 8, 19, 24, 3, 10);`

## Запуск

```java
Main.main(args)
// Вывод: [12, 8, 24, 10]
```
