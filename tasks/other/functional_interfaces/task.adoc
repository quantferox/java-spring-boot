# Functional Interfaces: FilterNumbers

## Описание

Дан `ArrayList<Integer>` из различных чисел.
Задача — создать функциональный интерфейс `NumberCondition` с методом `boolean test(int number)`,
написать метод `filterNumbers`, который принимает список и условие (lambda) и возвращает
новый список с элементами, прошедшими проверку.

В `Main` через lambda:

1. Отфильтровать и вывести только **чётные** числа.
2. Отфильтровать и вывести числа **больше 20**.

Исходный список: `[5, 12, 25, 8, 30, 7, 18]`

## Запуск

```java
Main.main(args)
// Вывод:
// [12, 8, 30, 18]
// [25, 30]
```
