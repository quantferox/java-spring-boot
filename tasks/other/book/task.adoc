# Book: Comparable — сортировка по страницам

## Описание

Класс `Book` (поля: `String title`, `int pageCount`).
Задача — имплементировать `Comparable<Book>` и отсортировать книги
по количеству страниц **по возрастанию**.

## Запуск

```java
Main.main(args)
// Вывод: книги от наименьшего pageCount к наибольшему
```
