# Sorted Count: Stream API

## Описание

Эта задача состоит из двух частей:

Отсортируйте данный список неупорядоченных чисел (5, 1, 9, 2, 7) по
возрастанию с помощью sorted() и выведите его на экран.

Найдите количество чисел в этом списке, которые больше 5, с помощью count().

## Запуск

```java
Main.main(args)
// Вывод:
// 1
// 2
// 5
// 7
// 9
// 2
```
