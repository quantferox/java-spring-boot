# Student: Comparable — сортировка по баллам

## Описание

Класс `Student` (поля: `String name`, `double score`).
Задача — имплементировать `Comparable<Student>` и отсортировать студентов
по набранным баллам **по убыванию** (студент с высшим баллом — первый).

## Запуск

```java
Main.main(args)
// Вывод: студенты от наибольшего score к наименьшему
```
