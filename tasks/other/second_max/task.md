# Second Max + Utils

## Описание

Три статических метода:

1. `findSecondMax(int[] numbers)` — найти второй максимум в массиве.
   Вернуть `-1`, если массив null, содержит меньше 2 элементов или второго уникального максимума нет.
2. `length(String value)` — вернуть длину строки, null-safe (null → 0).
3. `countVowels(String value)` — подсчитать гласные (a, e, i, o, u), null-safe.

## Запуск

```java
Main.main(args)
// Пример: findSecondMax({4,7,2,7,9,4,3}) → 7
```
