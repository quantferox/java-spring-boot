# Deadlock (Взаимная блокировка)

## Описание

Два потока захватывают два общих ресурса (lockA и lockB) в обратном порядке,
что приводит к классической взаимной блокировке.

## Условия Коффмана (все четыре должны выполняться)

1. **Mutual Exclusion** — ресурс удерживается только одним потоком.
2. **Hold and Wait** — поток удерживает один ресурс и ждёт второй.
3. **No Preemption** — ресурс нельзя принудительно забрать.
4. **Circular Wait** — поток A ждёт ресурс потока B, поток B ждёт ресурс потока A.
